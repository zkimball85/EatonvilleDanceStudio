Eatonville Dance Studio Website



website to show/promote Eatonville Dance studio and see upcoming events.

viewers should be able to create their own account as long as they have a dancer with the studio (rec/comp).



As a user, I can create/register an account after dancer is verified as a current student.

* Issue: Create user
* Issue: Verify student status
* Issue: Assign classes to student/dancer
* Issue: Sign up for classes/events/fundraisers
* Issue: add and save photos to dancer/student profile for main page slideshow
* Issue: View past classes/events/event placing/fundraising



As a user, I can log in and see my personalized profile, where I can manage the dancer and their classes and upcoming events(comps, recitals)

* Issue: Access account balance and online pay portal
* Issue: Pay balance amount, per season, per class, per event. 



As a Instructor, I can view my registered students and classes as well as post updates and notices for those signed up in the class. As well as log hours for payroll or track private lessons.

* Issue: Create Instructor
* Issue: Create Course Class page and save class and student list to Db
* Issue: Give Instructors CRUD functionality for students and courses
* Issue: Give registered students view only access for the class
* Issue: Communicate with dancers and parents with message board



As a Director, I can view the entire studio list of registered dancers, accounts, instructors classes and hours along with private lessons. I can see who has paid or how much of their total balance is paid or unpaid.

* Issue: view and edit abilities on any dancers profile excluding payment or signup.
* Issue: view instructors/teachers profiles including class roster, studio use, hours worked/taught, classes being taught.
* Issue: access students/dancers payments, verify payments and balances, invoicing for billing.
* Issue: encrypted messaging between teachers, dancers, parents.
* Issue: Create new class, assign instructor, verify students for each class.
* Issue: Create new event/competition with venue, dates, dances, FAQs.
